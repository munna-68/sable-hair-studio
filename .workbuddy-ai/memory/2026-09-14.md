## THE BUG WORTH REMEMBERING
Reveal state was originally a CSS class (`is-revealed`) added imperatively.
**React rewrites `className` whenever a component's class string changes**
(e.g. `"booking-step muted-step"` → `"booking-step"`), which silently wiped the class —
3 of 4 booking steps stayed at `opacity:0`. Fix: store reveal state in a
`data-revealed` **attribute**, which React never renders and therefore never clobbers.
